# Reference Images

Screenshots from other Pokemon map implementations for design reference:

- **game8** - Shows radius visualization around benches/fly points (UX we adopted)
- **serebii** - Best for precise spawn point data with exact Pokemon percentages
- **gamerguides** - Shows what to avoid (too much clutter with items/TMs)
- **polygon** - Large icons and zone-based spawns (not precise enough)
- **pokeos** - Doesn't show individual spawn points

These are kept as design reference only and are not deployed.
